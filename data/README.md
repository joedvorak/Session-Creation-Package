# Data Files

Input data for SMART session organization.

## Subdirectories

| Directory | Contents |
|-----------|----------|
| `submissions/` | Presentation submission files (CSV, Excel) |
| `committees/` | Committee information files |
| `hybrid/` | Hybrid session pre-assignments |

## File Formats

SMART supports CSV and Excel (.xlsx) files. Use the column mapping feature 
in the apps to map your columns to required fields.

### Required Fields for Presentations

- Submission ID (or auto-generated)
- Title
- Abstract

### Optional Fields

- Presenter name
- Presenter email
- Presenter affiliation
- Session assignment (for progress tracker)
